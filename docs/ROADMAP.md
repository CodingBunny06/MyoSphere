# Roadmap

## Stage 0 — Foundation and validation
- [ ] Approve product scope and architecture.
- [ ] Establish security and data-handling rules.
- [ ] Set up TypeScript workspace and CI.
- [ ] Build frontend shell and local API health check.
- [ ] Connect SQLite through a repository layer.
- [ ] Prototype a lightweight 3D scene.
- [ ] Validate performance on target hardware.

## Stage 1 — Core application
- [ ] Dashboard shell.
- [ ] Exercise catalogue.
- [ ] Workout templates and session logging.
- [ ] Local persistence and schema migrations.
- [ ] Basic history and personal records.

## Stage 2 — Nutrition
- [ ] Food and meal data model.
- [ ] Food search integration.
- [ ] Manual food and recipe entry.
- [ ] Nutrient summaries and hydration.
- [ ] Source attribution and licence review.

## Stage 3 — Body progress and 3D experience
- [ ] Private progress check-in timeline.
- [ ] Local progress photo import and management.
- [ ] Side-by-side photo comparison.
- [ ] Optional measurement history.
- [ ] GLB asset pipeline and interactive anatomy prototype.
- [ ] Exercise animation playback and muscle-group mapping.
- [ ] Performance and accessibility review.

## Stage 4 — Insights
- [ ] Transparent training analytics.
- [ ] Optional AI provider interface.
- [ ] Consent and data disclosure controls.
- [ ] Non-medical insight boundaries.

## Stage 5 — Mobile and broader self-hosting
- [ ] Evaluate Capacitor.
- [ ] Test mobile performance and storage.
- [ ] Remote-access threat model.
- [ ] Authentication, TLS, and hardened deployment before remote access.
- [ ] Backup, restore, export, and deletion workflows.

## Stage 6 — Accounts and community privacy
- [ ] Multi-user account and authentication model.
- [ ] Public/private profile setting (private by default).
- [ ] Per-section and per-item visibility controls.
- [ ] Follow requests and approval workflow.
- [ ] Follower removal and account blocking.
- [ ] Privacy preview and visibility-change confirmation.
- [ ] Server-side authorization and private media delivery.
- [ ] Tests for private profile, follow, block, and data-leakage cases.
- [ ] Explicit opt-in sharing for progress photos and achievements.
