# Security Policy

## Supported versions

MyoSphere is in early development. No production release is currently supported.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues or discussions.

Until a dedicated private reporting address is published, use GitHub's private contact mechanisms to contact the repository owner. Include the affected version or commit, impact, reproduction steps, and a safe proof of concept where possible.

Please allow maintainers time to investigate and prepare a fix before public disclosure.

## Sensitive data

Never include real workout logs, nutrition records, measurements, photographs, API keys, passwords, or database files in vulnerability reports. Use synthetic examples.
